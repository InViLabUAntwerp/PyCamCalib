RMS Reprojection Error

This plot is the primary tool for judging the quality of your calibration.

What is Reprojection Error?

For each image, the algorithm uses the calculated camera parameters to "reproject" the 3D board corners back into a 2D image. The reprojection error is the distance (in pixels) between the original detected corner and its reprojected position. A smaller distance means a better calibration.

How to Read the Plot:

  • Each bar represents the average reprojection error for a single image. Taller bars indicate images that contribute more error to the overall calibration.
  • The dashed line shows the overall Root Mean Square (RMS) error across all images. A good calibration typically has an RMS error below 0.5 pixels, and an excellent one is below 0.2 pixels.
  • Removing Outliers: Click on a bar to mark it for removal. It will turn red. Then, click the "Remove Outliers & Recalculate" button. This will perform a new calibration without the selected images, which can often significantly improve the final RMS error.
