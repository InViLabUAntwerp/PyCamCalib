Calibration Settings

This section configures how the calibration pattern is detected in your images.

Detector Type:

  • Checkerboard: The standard and most common calibration pattern. It is reliable but can be sensitive to lighting and perspective.
  • ChArUco: A more advanced pattern that combines a checkerboard with ArUco markers. It is more robust to occlusions (parts of the board being hidden) and provides highly accurate corner detection.

ChArUco Preset:

  • Auto-Detect Board: If you are using a custom ChArUco board, the algorithm will attempt to automatically determine its dimensions from the images. This is flexible but may fail if the board is not clearly visible in the first few images.
  • Wenglor Board: Select this if you are using the specific Wenglor ChArUco board. This uses pre-configured parameters for faster and more reliable detection.

Square Size (mm):

This is the most critical parameter for a metrically accurate calibration. Measure the side length of a single square on your physical calibration board as precisely as possible and enter the value in millimeters.

Board Corners (Cols × Rows):

Specify the number of inner corners on your checkerboard (e.g., a standard 9x6 board has 8 columns and 5 rows of inner corners). If left as "Auto", the system will try to detect the size automatically, which is convenient but may be less reliable than specifying it manually.

Require all corners (Absolute):

If checked, only images where all specified inner corners are detected will be used for calibration. This enforces a very high-quality dataset but may discard images where the board is partially out of frame.

Pixel Size (μm):

This optional parameter is the physical size of a single pixel on your camera's sensor (e.g., 3.45 μm). You can find this value in your camera's datasheet. If provided, the tool can calculate and display the focal length in millimeters (mm), which is often more intuitive than pixels.
